# 🚗 Car Price Prediction System

A Machine Learning project developed as part of my **AI/ML Internship at InternPe**.

The project predicts the estimated resale price of a used car based on important details such as company, manufacturing year, kilometres driven, and fuel type.

---

## 📌 Project Overview

The **Car Price Prediction System** uses **Random Forest Regression** to estimate the price of a used car.

The project includes:

- Dataset analysis
- Data cleaning and preprocessing
- Missing-value handling
- Duplicate removal
- Feature preprocessing
- Machine Learning model training
- Random Forest Regression
- Model saving and loading
- Graphical User Interface (GUI)
- Automatic sample data filling
- Price prediction
- Prediction history
- Prediction history graph
- CSV export

---

## 🎯 Objective

The main objective of this project is to build a simple and user-friendly Machine Learning application that can estimate the resale value of a used car based on its characteristics.
